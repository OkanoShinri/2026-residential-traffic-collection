# データセット収集へのご協力のお願い

`script.py` は `https://quic-resip.otsu36.net` へ HTTP/3 と HTTP/2 のリクエストを 2000 回ずつ（合計 4000 回）送るだけのスクリプトです。
中身は 100 行未満です。

## 記録される情報（事前に同意をお願いします）

- `attempts.log`: 各試行の時刻・成否・所要時間
- `sslkeys.log`: このスクリプトが行った通信の TLS 鍵。これによりサーバー側で記録した通信の中身を復号できます（他のアプリの通信の鍵は含まれません）
- あなたのグローバル IP アドレス（サーバー側で記録されます）

パケットキャプチャはサーバー側で行うため、皆さんのお手元での作業はリクエストの送信のみです。

## 手順

1. uv をインストールします（https://docs.astral.sh/uv/getting-started/installation/ ）。
2. これから実験を行う旨を岡野までお知らせください(パケットキャプチャを開始します)。
3. このフォルダで次を実行します。初回は依存関係が自動でインストールされます。

   ```
   uv run scripts.py
   ```

4. 表示される説明をお読みください。同意していただける場合は `yes` と入力してください。
5. 70〜120 分ほどで終わります。途中でスリープしないようにしてください。
6. 終了したら岡野までお知らせください(パケットキャプチャを停止します)。
7. 終了後、このフォルダにある `attempts.log` と `sslkeys.log` をご提出ください。

## うまくいかないとき

`err` が続く場合、 `attempts.log` をお見せいただければこちらで確認します。

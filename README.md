# データセット収集へのご協力のお願い

`script.py` は `https://quic-resip.otsu36.net` へ HTTP/3 と HTTP/2 のリクエストを 2000 回ずつ（合計 4000 回）送るだけのスクリプトです。
中身は 100 行未満です。

## 記録される情報（事前に同意をお願いします）

- `attempts.log`: 各試行の時刻・成否・所要時間
- `sslkeys.log`: このスクリプトが行った通信の TLS 鍵。これによりサーバー側で記録した通信の中身を復号できます（他のアプリの通信の鍵は含まれません）
- あなたのグローバル IP アドレス（サーバー側で記録されます）

パケットキャプチャはサーバー側で行うため、皆さんのお手元での作業はリクエストの送信のみです。

## 手順(windowsの方)
1. これから実験を行う旨を岡野までお知らせください。
1. このページの上のほうにある緑色の 「<> Code」 ボタンをクリックし、出てきたメニューの一番下にある 「Download ZIP」 をクリックしてください。
3. 「ダウンロード」フォルダに ZIP ファイルが保存されます。それを 右クリック → 「すべて展開」 → 「展開」 の順にクリックしてください。
3. 展開してできたフォルダの中にある run.bat（拡張子が表示されない設定では歯車のアイコンの run）をダブルクリックしてください。
> 青い画面で「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」 をクリックしてください。「発行元を確認できませんでした」という画面が出た場合は 「実行」 をクリックしてください。
4. 表示される説明をお読みください。内容を読み、同意いただける場合は`yes`と入力して Enter キーを押してください。
5. 画面に1行ずつ結果が流れていきます。70〜90 分ほどで終わります。終わるまで画面を閉じず、パソコンをスリープさせないでください。ノートパソコンの場合は電源につないでおくと安心です。
6. 「完了しました」と表示されたら終了ですので、岡野までお知らせください。その後同じフォルダにある次の2つのファイルをご提出ください。

- `attempts.log`（拡張子が表示されない設定では`attempts`）
- `sslkeys.log`（同じく`sslkeys`）

## 手順(windows以外の方)

1. uv をインストールします（https://docs.astral.sh/uv/getting-started/installation/ ）。
2. これから実験を行う旨を岡野までお知らせください(パケットキャプチャを開始します)。
3. このディレクトリで次を実行してください。初回は依存関係が自動でインストールされます。

   ```
   uv run scripts.py
   ```

4. 表示される説明をお読みください。内容を読み、同意いただける場合は`yes`と入力して Enter キーを押してください。
5. 70〜90 分ほどで終わります。途中でスリープしないようにしてください。
7. 終了したら岡野までお知らせください(パケットキャプチャを停止します)。その後`attempts.log`と`sslkeys.log` をご提出ください。

## うまくいかないとき

`err` が続く場合、 `attempts.log` をお見せいただければこちらで確認します。
